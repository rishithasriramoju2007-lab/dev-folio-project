# Responsive Dev-Folio Landing Page

## Project Description

This project is a responsive personal portfolio website created using HTML, CSS, Bootstrap 5, and JavaScript.

The website showcases my introduction, technical skills, and contact information. It includes a responsive navigation bar, hero section, skill cards, contact form, and footer.

The contact form uses JavaScript validation to check the user's name, email address, and message before submission.

## Features

- Responsive Bootstrap navigation bar
- Personal introduction section
- Six technical skill cards
- Responsive layout for different screen sizes
- Professional and clean design
- Contact form with JavaScript validation
- Name validation
- Email validation
- Message length validation
- Error messages for invalid inputs
- Success message for valid submission
- Footer with social links

## Technologies Used

- HTML5
- CSS3
- Bootstrap 5
- JavaScript
- Git
- GitHub
